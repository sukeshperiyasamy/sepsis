Beginner's Strategy for Simulating Bacterial
Biomarkers in Gaussian and Obtaining Raman
Spectra
Prepared for: SERS-Based Sepsis Biomarker Detection Project
Date: November 2025
Molecules: N-acetylmuramic acid (MurNAc), Lipoteichoic Acid (LTA), Lipopolysaccharide (LPS)
Executive Summary
This step-by-step guide is designed for beginners entering computational chemistry and Raman
spectroscopy simulation. It covers the complete workflow: molecular structure preparation →
geometry optimization → vibrational frequency calculation → Raman spectrum generation and
analysis using Gaussian 16/09 software combined with GaussView (visualization) and GaussSum
(spectral analysis).
Target Outcome: Generation of theoretical Raman spectra peaks (wavenumbers and intensities) that
can be compared with experimental SERS data for biomarker identification and sepsis diagnostics.
Part 1: Pre-Simulation Setup & Prerequisites
1.1 Software Installation & Environment
Required Software:
Gaussian 16 or 09 – Quantum chemistry calculation engine
GaussView 6 or compatible – Molecular visualization and input file generation
GaussSum 3.0 – Post-processing and spectrum generation from Gaussian output
Avogadro 1.2+ (Free, Open-Source) – Alternative for initial structure drawing and format
conversion
Text editor (e.g., Notepad++, nano) – For manual input file editing
Spreadsheet software (Excel, LibreOffice Calc) – For data visualization and peak analysis
Installation Tips:
Install Gaussian and GaussView on a workstation or cluster with adequate RAM (minimum 8GB;
16GB+ recommended for larger molecules).
GaussSum and Avogadro are free and platform-independent (Windows, Mac, Linux).
Verify Gaussian installation by testing a simple water (H₂O) optimization job.

Part 2: Molecular Structure Preparation (Step 1–3)
Step 1: Obtain or Draw Initial Molecular Structure
For Beginners – Three Approaches:
Option A: Download Pre-Optimized Structures from PubChem
1. Visit https://pubchem.ncbi.nlm.nih.gov
2. Search for the molecule (e.g., "N-acetylmuramic acid" or use CID: 82756)
3. Download as SDF or MOL file format
4. Open in GaussView or Avogadro
PubChem CIDs for Target Molecules:
N-Acetylmuramic acid: CID 82756 or 5462244
Lipoteichoic acid (representative): CID 137349712
Lipid A: CID 9877306
Note: O-antigen has species-specific variability; use E. coli O111 or representative unit structures.
Option B: Manual Structure Drawing in Avogadro (Recommended for Learning)
1. Open Avogadro → File → New
2. Select Draw Tool (pencil icon)
3. Left-click to add atoms; select element from dropdown (C, H, O, N, P, S)
4. Click and drag to create bonds (adjust bond order: 1=single, 2=double, 3=triple)
5. Enable "Adjust Hydrogens" checkbox to auto-populate H atoms
6. Click Extensions → Optimize Geometry (uses UFF force field for rough pre-optimization)
7. Save as .mol file

--- page 3 ---
Option C: Use GaussView to Build Structure
1. Launch GaussView
2. Select Element Fragment from toolbar
3. Click in the workspace to add atoms
4. Use R-Group Fragment to add substituents
5. Click Edit → Clean Geometry to regularize structure
6. Click Edit → Symmetrize to identify point group symmetry
7. Save as .gjf (Gaussian input file) or .com
For Complex Biomarkers (LTA, LPS): Start with the smallest repeating unit or monomeric
substructure to reduce computational cost. For example:
For LTA: model a glycerol-phosphate dimer or single repeat unit rather than the full polymer.
For LPS: use Lipid A core alone or Lipid A + one Kdo residue as a tractable model.
For MurNAc: use the single residue or MurNAc-GlcNAc dipeptide.
Step 2: Import Structure into GaussView and Verify Geometry
1. Open GaussView
2. File → Open → Select your .mol, .sdf, or .gjf file
3. Verify initial structure:
Inspect bond lengths (right-click on bond to measure)
Check for missing atoms or incorrect connectivity
Ensure stereochemistry is correct (wedge/dash bonds for stereocenters)
4. Clean and Prepare:
Click Edit → Clean Geometry (optimizes bond angles/lengths using force field)
Click Edit → Symmetrize (identifies point group symmetry; optional but informative)
5. Save as GaussView File:
File → Save as .gv (retains 3D structure for later use)
Step 3: Add Charge and Multiplicity
1. In GaussView:
Click Molecule → Properties
Set Charge: 0 (for neutral biomarkers; adjust if ionized)
Set Multiplicity: 1 (for closed-shell; use 2 for radicals)
Default: Most bacterial biomarkers at physiological pH are charge 0–2– (anionic due to
phosphates)

--- page 4 ---
2. For phosphate-rich biomarkers (LTA, LPS, MurNAc with phosphate):
Physiological state: Charge = –1 to –3 (deprotonated phosphates)
Best practice: Model at both neutral and anionic states to compare SERS activity
Consider solvent effects (aqueous environment) — set PCM (Polarizable Continuum Model)
in Gaussian input
Part 3: Geometry Optimization (Step 4–6)
Step 4: Generate Gaussian Input File for Geometry Optimization
In GaussView:
1. Click Calculate → Gaussian Calculation Setup
2. A new window appears: Gaussian Calculation Setup
3. Job Type Tab:
Select Opt (Geometry Optimization)
Do NOT select Freq yet; only do Opt first
4. Method Tab:
Functional: B3LYP (hybrid DFT; good balance of speed and accuracy)
Basis Set: 6-31G(d) (good starting point; 6-311G(d) for refined)
Solvent Model (optional): PCM=UFF (for aqueous environment like sepsis)
5. Additional Tab (Optional):
Check Symmetry: Auto (lets Gaussian detect symmetry)
Check Unit cell (if modeling periodic systems; not applicable for isolated molecules)
6. Route Line Preview: Should show:
# B3LYP/6-31G(d) Opt
7. Click Submit (or save input file first)
Alternative: Manual Input File Creation
Create a text file with .com or .gjf extension:
%chk=MurNAc_opt.chk
%mem=8GB
%nproc=4
# B3LYP/6-31G(d) Opt
N-acetylmuramic acid geometry optimization
0 1
C 0.00000 0.00000 0.00000

--- page 5 ---
O 1.20000 0.00000 0.00000
... (Cartesian coordinates of all atoms)
Key Input File Components:
%chk=filename.chk – Checkpoint file (stores intermediate data)
%mem=8GB – Memory allocation (adjust based on system)
%nproc=4 – Number of processors
# B3LYP/6-31G(d) Opt – Route line (method, basis, job type)
Title line (any descriptive text)
Charge and Multiplicity (e.g., 0 1 for neutral singlet)
Molecular geometry (Cartesian or Z-matrix coordinates)
Step 5: Submit Optimization Job to Gaussian
On a Local Machine:
1. In GaussView, click Submit (after filling in the Calculation Setup)
2. Alternatively, from terminal:
g16 MurNAc_opt.com MurNAc_opt.log
On a High-Performance Computing (HPC) Cluster:
1. Prepare a job submission script (e.g., SLURM, PBS):
#!/bin/bash
#SBATCH --job-name=MurNAc_opt
#SBATCH --nodes=1
#SBATCH --cpus-per-task=4
#SBATCH --mem=16G
#SBATCH --time=12:00:00
module load gaussian
g16 MurNAc_opt.com MurNAc_opt.log
2. Submit:
sbatch submit_job.sh
Monitor Progress:
Check logfile for keywords: "Optimization completed" (success) or "Error" (failure)
GaussView can display geometry update in real-time
Typical warnings: "Initial guess from Harris functional" (normal)

--- page 6 ---
Step 6: Verify Optimization Convergence
1. Open output file (.log or .out) in GaussView:
File → Open → Select .log file
GaussView displays optimized structure
2. Check Key Convergence Indicators:
No negative frequencies: Confirms structure is at a minimum (not a saddle point)
SCF Convergence: Last line should state "convergence achieved"
Energy: Final energy value shown in Hartrees (e.g., –123.456789)
3. Common Issues:
Imaginary frequencies during optimization: Molecule geometry is not at a minimum; re-
optimize with tighter convergence criteria
No convergence after 100 steps: Increase max steps with Opt=(MaxCycles=200) in route
line
Part 4: Vibrational Frequency & Raman Calculation (Step 7–8)
Step 7: Generate Input File for Freq=Raman Calculation
Critical: Always run frequency calculations using the same method and basis set as the
optimization. Do NOT compute frequencies at a different level of theory than the optimized structure.
In GaussView (Recommended Workflow):
1. File → Open the optimized structure (MurNAc_opt.log from Step 5)
2. Click Calculate → Gaussian Calculation Setup
3. Job Type Tab:
Select Freq (Frequency calculation)
Check Raman (to calculate Raman activity; NOT just IR)
4. Method Tab:
Functional: B3LYP (same as optimization)
Basis Set: 6-31G(d) (same as optimization)
5. Route Line Preview:
# B3LYP/6-31G(d) Freq=Raman
6. Use Checkpoint: Enable geom=allcheck to read optimized geometry from .chk file
Route line becomes:
# B3LYP/6-31G(d) geom=allcheck guess=read Freq=Raman

--- page 7 ---
7. Click Submit
Manual Input File (Using Checkpoint):
%oldchk=MurNAc_opt.chk
%chk=MurNAc_freq.chk
%mem=8GB
%nproc=4
# B3LYP/6-31G(d) geom=allcheck guess=read Freq=Raman
Frequency and Raman calculation for MurNAc
0 1
(Leave molecular coordinates blank; Gaussian reads from .chk file)
Step 8: Execute Frequency/Raman Calculation
Submit job (same as Step 5):
g16 MurNAc_freq.com MurNAc_freq.log
Expected Output (from .log file):
Vibrational frequencies (cm⁻¹) for each normal mode
Raman activity (in Ų) for each mode
IR intensities (km/mol)
Force constants
Part 5: Spectrum Generation & Analysis (Step 9–10)
Step 9: Extract Raman Spectrum Using GaussSum
GaussSum is the key tool for converting raw vibrational data into publication-ready spectra.
Step-by-Step in GaussSum:
1. Launch GaussSum (free, open-source; www.gausssum.sourceforge.net)
2. File → Open → Select MurNAc_freq.log (the Gaussian frequency output)
3. Left Panel → Select "Frequencies"
4. Set Raman Spectral Parameters:
Start wavenumber: 0 cm⁻¹
End wavenumber: 3500 cm⁻¹ (covers most vibrational modes)
Number of points: 1000 (higher = finer resolution)

--- page 8 ---
FWHM (Full Width Half Maximum): 10 cm⁻¹ (typical for Raman)
Wavelength (for Raman intensity correction):
785 nm (common in SERS; NIR laser)
532 nm (visible laser)
1064 nm (Nd:YAG)
Temperature: 298 K (or match your experimental conditions)
Scaling factor: 0.98 (empirical correction for DFT overestimation; consult literature)
5. Click "GaussSum icon" → generates Raman spectrum
6. Output:
Automatic plot displayed
Data exported to IRSpectrum.txt and RamanSpectrum.txt (in gausssum3 subfolder)
Key GaussSum Outputs:
RamanSpectrum.txt: Contains wavenumber (cm⁻¹), Raman activity, intensity
Format: Tab-separated; easily imported into Excel or Origin for visualization
Step 10: Peak Identification & Data Analysis
In Excel or LibreOffice:
1. Import RamanSpectrum.txt:
File → Open → Select RamanSpectrum.txt
Select "Tab-delimited" import option
2. Create Peak Table:
Wavenumber (cm⁻¹) Raman Intensity Functional Group Assignment Biomarker Relevance
580 High P–O stretch (phosphate) LTA, LPS (diagnostic)
1050 Medium C–O stretch (glycosidic) MurNAc, LTA, LPS
1200 Medium Amide III (peptide) MurNAc
1600 High Amide II (N–H bend) MurNAc
2900 Medium C–H stretch All molecules
3. Plot Raman Spectrum:
X-axis: Wavenumber (cm⁻¹)
Y-axis: Raman Intensity (or Activity)
Mark prominent peaks with functional group labels
Add experimental reference spectra (if available) for comparison
4. Quantitative Analysis:
Peak position consistency: Compare calculated vs. experimental ±5–10 cm⁻¹

--- page 9 ---
Intensity ratios: Phosphate peaks should dominate for LTA/LPS
Frequency scaling: If discrepancy >10%, apply correction factor (e.g., 0.98 × frequency)

Best Practices for Accurate Results
1. Always use the same method for both Opt and Freq jobs (consistency is critical)
2. For biomarkers with phosphates: Include solvent model (PCM for aqueous)
3. Validate geometry: Inspect bond lengths/angles against literature values
4. Scale frequencies: Apply empirical scaling (typically 0.95–0.98 for B3LYP/6-31G)
5. Experimental comparison: If experimental Raman is available, refine basis set or functional
6. Document all parameters: Keep record of method, basis, temperature, laser wavelength for
reproducibility
Part 7: Advanced Considerations for Biomarker Molecules
Handling Complex & Large Biomarkers
Problem: Full LPS or LTA polymers are computationally intractable (hundreds of atoms, hours-to-days
runtime).
Solution Strategy:
1. Model Only the Diagnostic Unit:
MurNAc: Use single residue ✓ Tractable

--- page 10 ---
LTA: Use glycerol-phosphate monomer or dimer (not full polymer) ✓ ~10–30 min
LPS: Use Lipid A core (not full O-antigen) ✓ ~2–4 hours
O-antigen: Use representative disaccharide repeat unit ✓ ~30–60 min
2. Validate Approach:
Compare predicted SERS peaks of truncated model with full biomarker spectra (if literature
available)
Expect diagnostic peaks (phosphate at ~580 cm⁻¹, amide bands) to remain representative
3. Consider Multiple Conformations:
Biomarkers may have multiple low-energy conformers
Run optimization from 2–3 different starting geometries
Compare Raman spectra across conformers
Report most stable (lowest energy) conformation
Ionization States & pH Effects
Bacterial biomarkers at physiological pH (7.4) are typically deprotonated and anionic:
Phosphate groups (–PO₄²⁻ vs. –PO₄³⁻)
Carboxylate groups (–COO⁻)
Recommendation: Model both protonated and deprotonated forms:
Neutral form: Charge = 0 (simpler, faster)
Anionic form: Charge = –1, –2, or –3 (more realistic for sepsis biomarkers)
Compare Raman shifts; phosphate peaks are most diagnostic and sensitive to protonation
Molecular Solvent Effects (Optional but Recommended)
For physiologically relevant predictions, include aqueous solvation:
In Gaussian input route line, add:
# B3LYP/6-31G(d) Opt SCRF=(PCM,Solvent=Water)
Effect: Slight red-shift of frequencies; improves agreement with experimental aqueous SERS data.
Part 8: Integration with SERS Experimental Campaign

Comparing Theory to Experiment
1. Collect experimental SERS spectra of reference biomarkers (MurNAc, LTA, Lipid A) using same
laser wavelength as simulated in GaussSum (e.g., 785 nm)
2. Align peaks: Shift calculated spectrum if systematic offset observed (e.g., 1–2% frequency shift
common)
3. Build spectral library: Create database of theoretical + experimental peaks for each biomarker
4. Clinical validation: Use combined spectral library to identify unknowns in patient samples
Multiplexing Strategy
For sepsis diagnostics, you may target multiple biomarkers simultaneously:

Part 9: Quick Reference Workflows
Minimal Workflow (Learning; ~1–2 hours total)
1. Download N-Acetylmuramic acid (CID 82756) from PubChem as SDF
2. Open in GaussView → Geometry Optimization B3LYP/6-31G(d) (~30 min)
3. Frequency/Raman calculation on optimized structure (~30 min)
4. Open output in GaussSum → Generate Raman spectrum (2 min)
5. Plot and compare to literature
Full Workflow (All three biomarkers; ~24–48 hours total)
For each biomarker (MurNAc, LTA, Lipid A):
1. Prepare structure (30 min)
2. Geometry optimization (2–4 hours)
3. Frequency/Raman (4–8 hours)
4. Spectrum generation &amp; analysis (30 min)
5. Comparative analysis across all three (1 hour)
