STEP 4: ALS BASELINE CORRECTION                            [DONE]
------------------------------------------------------------------------
- Method: Asymmetric Least Squares (ALS)
- Parameters:
    lambda = 1e5 (smoothness - larger = smoother baseline)
    p = 0.001 (asymmetry - smaller = hugs bottom of spectrum)
    iterations = 10
- Result: Background becomes flat, peaks remain unchanged
- Applied to both NAM and Glass spectra
- Corrected Intensity = Raw Intensity - Baseline

STEP 5: SAVITZKY-GOLAY SMOOTHING                           [DONE]
------------------------------------------------------------------------
- Method: Savitzky-Golay filter
- Parameters:
    Window Length = 11
    Polynomial Order = 3
- Result: Noise reduced, peak shapes preserved
- No over-smoothing observed

STEP 6: MIN-MAX NORMALIZATION                              [DONE]
------------------------------------------------------------------------
- Formula: I_norm = (I - I_min) / (I_max - I_min)
- Result: All spectra normalized to range [0, 1]
- Allows direct comparison between spectra

STEP 7: AVERAGE REPLICATES                                 [DONE]

For Methods Section of Paper:

"Raman spectra were acquired using a BWS465-785H spectrometer (B&W Tek)
with 785 nm excitation. Measurements were performed at 70% laser power,
60 s integration time, and 5 accumulations per spectrum. Three different
spots on the sample were measured for reproducibility.

Data processing was performed in Python using custom scripts. The raw
spectra were cropped to the 400-1800 cm-1 fingerprint region. Baseline
correction was performed using the Asymmetric Least Squares (ALS)
algorithm (lambda = 1e5, p = 0.001, 10 iterations). Spectra were
smoothed using a Savitzky-Golay filter (window = 11 points, polynomial
order = 3) and normalized using min-max normalization. The three spot
measurements were averaged to produce the final spectrum. Peak detection
was performed using scipy.signal.find_peaks with prominence threshold
of 0.02 and minimum peak distance of 10 data points."

ISSUE 3: 90%-60s ANOMALOUS SNR EXPLAINED
------------------------------------------------------------------------
Problem: SNR for "90%, 60s, 5acc" = -0.7 (negative, physically impossible)

Root Cause Identified: EXCESSIVE FLUORESCENCE / SAMPLE BURNING

Diagnostic Results:
  Metric                         90%, 60s        70%, 60s
  ----------------------------------------------------------
  Max raw counts                 63099           63099
  Saturated pixels (=65535)      0               0
  Signal (900-1100 peak-median)  -894            +2667
  Noise std (1700-1800)          1038            110
  SNR (signal/noise)             -0.9            +24.3
  Noise median (1700-1800)       -1188           +1191

  Key finding: NEGATIVE noise median (-1188 counts)
  This means the Dark Subtracted values are negative in the noise region.

  Explanation:
    At 90% power with 60s integration:
    - The dark current measurement was higher than the actual signal
    - OR the sample fluorescence created a sloped baseline that
      inverts after dark subtraction
    - The Raman peaks at 900-1100 are BELOW the baseline
    - Result: all intensities become negative after dark subtraction

  Conclusion:
    90% power + 60s integration is TOO AGGRESSIVE for this sample.
    It causes either:
    (a) Sample burning/degradation during measurement
    (b) Excessive fluorescence overwhelming the detector
    (c) Dark current drift during long exposure

  Recommendation:
    EXCLUDE 90%-60s data from publication.
    Use 70%, 60s, 5acc as the optimal condition (SNR = 24.7).

  Figure generated: Figure_Investigation_90p60s.png/pdf
    Left column: 90% 60s data (anomalous)
    Right column: 70% 60s data (normal)
    Rows: Full spectrum / Signal region / Noise region
