1. DATA EXTRACTION METHODOLOGY
================================================================================

1.1 SOURCE DATA STRUCTURE
--------------------------
Each CSV file contains 2049 rows with the following structure:

Row 1:  integration times(sec), [5/10/15/20/25], Raman Shift, Intensity
Row 2:  laser_wavelength, 784.92, [shift value], [intensity value]
Row 3:  laser_powerlevel, [5-80], [shift value], [intensity value]
Rows 4-2049: ,, [Raman Shift (cm⁻¹)], [Intensity (a.u.)]

1.2 EXTRACTED PARAMETERS
-------------------------
From each CSV file, we extract:

METADATA (First 3 rows):
  • Integration Time (Column B, Row 1): Exposure duration in seconds
  • Laser Wavelength (Column B, Row 2): Excitation wavelength = 784.92 nm
  • Laser Power (Column B, Row 3): Laser power in Watts (5-80 W)

SPECTRAL DATA (Rows 4-2049):
  • Raman Shift (Column C): X-axis values in cm⁻¹ wavenumbers
  • Intensity (Column D): Y-axis values (Dark Subtracted #1 - background corrected)

1.3 DATA LOADING FUNCTION
--------------------------
Function: load_raman_csv(file_path)

Process:
  1. Open CSV file and read all lines
  2. Parse first 3 rows to extract metadata (integration time, wavelength, power)
  3. Loop through all remaining rows
  4. Extract columns C (Raman Shift) and D (Intensity)
  5. Convert to NumPy arrays for numerical operations
  6. Return dictionary with all extracted data

Output: Dictionary containing:
  - 'integration_time': float
  - 'power': float
  - 'wavelength': float
  - 'raman_shift': numpy array (2048 elements)
  - 'intensity': numpy array (2048 elements)
  - 'file_name': string

1.4 ERROR ESTIMATION (NOISE-BASED METHOD)
------------------------------------------
Function: estimate_noise(intensity, baseline_range=(0, 100))

Method: Baseline Standard Deviation
  • Extract baseline region: First 100 data points (far from peaks)
  • Baseline selection: The baseline region was selected at low Raman shift
    where no prominent Raman features were observed across all spectra.
  • Calculate standard deviation: σ_noise = std(baseline_intensities)
  • Use as error estimate for all measurements

Formula:
  σ_noise = √[Σ(Iᵢ - Ī)² / (N-1)]

Where:
  • Iᵢ = intensity at baseline point i
  • Ī = mean baseline intensity
  • N = number of baseline points (100)

Justification (Single Measurements):
  ✓ No replicate measurements available
  ✓ Baseline noise representative of detector noise floor
  ✓ Conservative estimate (includes shot noise + detector noise)
  ✓ Standard approach for single-acquisition spectroscopy
  ✓ Acceptable for publication when replicates unavailable

Limitations:
  ✗ Does not capture sample-to-sample variability
  ✗ Does not capture systematic errors
  ✗ Assumes noise stationary across spectrum

Typical Results:
  • Noise (σ): ~114 a.u. (1 standard deviation)
  • Signal: ~6,000 - 247,000 a.u. (peak area)
  • Signal-to-Noise Ratio: 50-2000 (excellent)

Error Bar Interpretation:
  • Vertical bars: ±1σ (68% confidence interval)
  • Represents measurement precision
  • Smaller bars at higher signals (better SNR)
  • Larger bars at lower signals (detector limited)

2. NORMALIZATION & METRIC DEFINITIONS (ENHANCED)
================================================================================

2.1 TIME-NORMALIZED INTENSITY
------------------------------
Definition: Removes trivial scaling from integration time

Formula:
  I_norm(time) = I_raw / t_integration

Units: [intensity units] / sec  →  a.u./sec

Purpose:
  • Enables fair comparison across different integration times
  • Reveals true instrument response independent of exposure duration
  • Required for meaningful power-dependence analysis

Justification:
  Signal accumulates linearly with time (ideal detector behavior).
  Normalization removes this trivial scaling to show power response.

2.2 POWER-NORMALIZED EFFICIENCY
--------------------------------
Definition: Signal strength per unit laser power

Formula:
  η_power = I_raw / P_laser

Units: [intensity units] / W  →  a.u./W

Purpose:
  • Quantifies power-to-signal conversion efficiency
  • Identifies non-linear power effects (heating, saturation)
  • Not used in main analysis (see energy-time efficiency below)

2.3 ENERGY-TIME EFFICIENCY (PRIMARY METRIC)
--------------------------------------------
Definition: Signal strength per unit energy and time investment

Formula:
  η_energy-time = I_raw / (P_laser × t_integration)

Units: [intensity units] / (W·sec)  →  a.u./(W·sec)

Purpose:
  • Identifies most cost-effective measurement conditions
  • Balances signal quality against experimental resources
  • Critical for optimization studies and high-throughput work

Interpretation:
  High efficiency: Maximum signal per unit energy-time investment
  Low efficiency: Diminishing returns (possible heating, saturation)

2.4 COMBINED NORMALIZATION APPROACH
------------------------------------
For Power Dependence Analysis (Plot 1):
  • Use: I_norm(time) = I_raw / t_integration
  • Why: Removes time scaling, shows pure power response
  • Result: Curves collapse to similar sensitivity (slope)

For Time Dependence Analysis (Plot 2):
  • Use: I_norm(time) = I_raw / t_integration  
  • Why: Shows rate of signal accumulation (intensity per second)
  • Result: Horizontal lines if perfectly linear with time

For Efficiency Analysis (Heatmap):
  • Use: η = I_raw / (P × t)
  • Why: Reveals optimal operating conditions
  • Result: Identifies sweet spots for efficient measurements

3. PEAK INTENSITY EXTRACTION
================================================================================

3.1 PURPOSE
-----------
Instead of plotting entire spectra (2048 points each), we extract a single
representative intensity value from each spectrum for quantitative analysis.

3.2 PEAK AREA INTEGRATION (PRIMARY METHOD)
-------------------------------------------
Function: get_peak_area(raman_shift, intensity, target_shift, window)

Method:
  1. Identify peak region (±window around target or global maximum)
  2. Integrate intensity using trapezoidal rule
  3. Return integrated area (more robust than peak height)

Formula:
  Area = ∫[shift-w to shift+w] I(ν) dν
       ≈ Σ I(νᵢ) × Δν  (trapezoidal approximation)

Where:
  • I(ν) = intensity at Raman shift ν
  • w = window size (default: ±10 cm⁻¹)
  • Δν = spacing between data points

Advantages over peak height:
  ✓ Robust to noise spikes
  ✓ Less sensitive to peak shape distortion
  ✓ Standard method for quantitative Raman spectroscopy
  ✓ Integrates signal over chemically relevant region

Implementation (NumPy 2.x compatible):
  area = np.trapezoid(intensities, raman_shifts)

3.3 PEAK HEIGHT METHOD (OPTIONAL/LEGACY)
-----------------------------------------
Function: get_peak_intensity(raman_shift, intensity, target_shift, window)

Method:
  • Parameters: target_shift = None (global max) or specific cm⁻¹
  • Method: Return maximum intensity value (single point)
  • Use case: Fast screening, legacy compatibility
  • Formula: peak_intensity = np.max(intensity)

Disadvantage:
  ✗ Sensitive to single-point noise
  ✗ Not recommended for quantitative work

Note: Peak AREA method is recommended and used by default in enhanced version.

3.4 GLOBAL MAXIMUM vs SPECIFIC PEAK SELECTION
----------------------------------------------

MODE 1: GLOBAL MAXIMUM (Current Default)
  Parameters: TARGET_RAMAN_SHIFT = None
  Method: Find strongest peak anywhere in spectrum
  
  Scientific Justification:
  • Purpose: System response characterization (not chemical analysis)
  • Goal: Test instrument linearity, power response, detector behavior
  • Rationale: Maximum signal → best SNR for system validation
  • Application: Quality control, instrument optimization
  
  Advantages:
    ✓ Maximum signal-to-noise ratio
    ✓ Representative of total system performance
    ✓ Independent of specific sample chemistry
    ✓ Suitable for instrument characterization studies
  
  Limitations:
    ✗ Not chemically specific
    ✗ Peak position may shift between samples
    ✗ Not suitable for quantitative chemical analysis

MODE 2: SPECIFIC RAMAN PEAK (Optional)
  Parameters: TARGET_RAMAN_SHIFT = 520 (for Si reference)
  Method: Extract area within ±10 cm⁻¹ of target shift
  
  Scientific Justification:
  • Purpose: Chemical analysis of specific molecular vibration
  • Goal: Track concentration or crystal quality
  • Rationale: Chemically meaningful band selection
  • Application: Quantitative analysis, material characterization
  
  Advantages:
    ✓ Chemically specific
    ✓ Reproducible across samples
    ✓ Enables quantitative concentration analysis
    ✓ Standard approach for Raman quantitation
  
  Example targets:
    • 520 cm⁻¹: Silicon (reference standard)
    • 1000 cm⁻¹: Phenylalanine (biomolecules)
    • 1580 cm⁻¹: Graphite G-band (carbon materials)

3.5 CURRENT IMPLEMENTATION
---------------------------
Configuration:
  TARGET_RAMAN_SHIFT = None
  PEAK_METHOD = 'area'
  PEAK_WINDOW = 10 cm⁻¹

Meaning:
  • Uses GLOBAL MAXIMUM peak position
  • Integrates area within ±10 cm⁻¹ of maximum
  • Appropriate for INSTRUMENT CHARACTERIZATION study
  • Can be changed to specific shift for chemical analysis

6. PLOT 3: POWER-TIME HEATMAP (2D Visualization)
================================================================================

6.1 SCIENTIFIC PURPOSE
-----------------------
To visualize all 80 measurements in a single figure, revealing:
  • Overall trends across both variables
  • Interaction effects between power and time
  • Quick identification of optimal conditions
  • Data quality and consistency check

6.2 DATA ORGANIZATION
----------------------
Data structure: 2D matrix (intensity_matrix)
  Dimensions: 5 rows × 16 columns
  Rows: Integration times (5, 10, 15, 20, 25 sec)
  Columns: Power levels (5, 10, 15, ..., 80 W)
  Values: Peak intensities

Construction method:
  Initialize: intensity_matrix = zeros(5, 16)
  FOR i, integration_time in enumerate([5,10,15,20,25]):
    FOR j, power in enumerate([5,10,...,80]):
      intensity_matrix[i, j] = peak_intensity(time, power)

6.3 PLOTTING TECHNIQUE (DUAL HEATMAP)
--------------------------------------
Library: Seaborn (built on Matplotlib)
Figure size: 18" × 6" (side-by-side comparison)

Plot type: Dual Heatmap (Linear + Log Scale)

LEFT PANEL: LINEAR SCALE
  X-axis: Laser Power (W) - 16 tick marks
  Y-axis: Integration Time (sec) - 5 tick marks
  Color: Absolute Peak Intensity (a.u.)
  
  Visual encoding:
    • Colormap: 'YlOrRd' (Yellow-Orange-Red)
      - Low intensity = light yellow
      - High intensity = dark red
    • Annotations: Numerical values in each cell (format: integer)
    • Cell borders: 0.5pt gray lines for clarity
    • Colorbar: Labeled "Intensity (a.u.)"
  
  Purpose:
    • Shows absolute intensity values
    • Easy to identify maximum signal conditions
    • Intuitive for direct value reading

RIGHT PANEL: LOG SCALE (ENHANCED VISUALIZATION)
  X-axis: Laser Power (W) - 16 tick marks
  Y-axis: Integration Time (sec) - 5 tick marks
  Color: log₁₀(Peak Intensity + 1)
  
  Visual encoding:
    • Colormap: 'viridis' (perceptually uniform)
      - Dark purple = low intensity (log ≈ 3.0)
      - Bright yellow = high intensity (log ≈ 4.0)
    • No annotations (focuses on patterns)
    • White gridlines for cell separation
    • Colorbar: Labeled "log₁₀(Intensity)"
  
  Purpose:
    • Reveals trends across full dynamic range (40×)
    • Low-intensity details visible (not washed out)
    • Better for wide-range data (6,000 to 247,000)
    • Standard for spectroscopy with large dynamic range
  
  Mathematical justification:
    • Linear scale: High values dominate, low values invisible
    • Log scale: Equal visual weight to all orders of magnitude
    • Formula: log₁₀(I + 1) to handle I = 0 gracefully

Code structure:
  # Linear heatmap
  sns.heatmap(intensity_matrix, cmap='YlOrRd', annot=True, ...)
  
  # Log heatmap
  log_matrix = np.log10(intensity_matrix + 1)
  sns.heatmap(log_matrix, cmap='viridis', annot=False, ...)

6.4 INTERPRETATION
-------------------
Pattern recognition:
  • Diagonal gradient: Both variables increase together
  • Vertical gradient: Power effect dominates
  • Horizontal gradient: Time effect dominates
  • Hotspots: Optimal measurement conditions

7. SLOPE (SENSITIVITY) ANALYSIS (NEW ENHANCEMENT)
================================================================================

7.1 SCIENTIFIC PURPOSE
----------------------
Quantify how measurement sensitivity (dI/dP) varies with integration time.

Reveals:
  • Detector linearity across conditions
  • Signal accumulation efficiency
  • Systematic trends or degradation
  • Diagnostic information for system performance

7.2 METHOD: LINEAR REGRESSION
------------------------------
Library: scipy.stats.linregress

For each integration time:
  1. Extract power array: P = [5, 10, 15, ..., 80] W
  2. Extract intensity array: I = [I(P₁), I(P₂), ..., I(P₁₆)]
  3. Fit linear model: I = m × P + c
  4. Extract slope (m), R², standard error

Output:
  • Slope (m): Sensitivity [a.u./sec/W] when normalized
  • Intercept (c): Zero-power offset (ideally ~0)
  • R²: Linearity quality (>0.99 = excellent)
  • Std Error: Uncertainty in slope estimate

7.3 RESULTS INTERPRETATION
---------------------------
Typical Results:
  Integration Time | Slope (Sensitivity) | R² (Linearity)
  -----------------|---------------------|---------------
  5 sec            | 104.407 a.u./sec/W | 0.9991
  10 sec           | 103.835 a.u./sec/W | 0.9931
  15 sec           | 106.722 a.u./sec/W | 0.9950
  20 sec           | 113.546 a.u./sec/W | 0.9790
  25 sec           | 120.832 a.u./sec/W | 0.9918
  AVERAGE          | 109.868 a.u./sec/W | 0.9916

Observations:
  ✓ All R² > 0.97 (good to excellent linearity)
  ✓ Average R² = 0.9916 (excellent)
  ✓ Slope varies by ~16% across integration times (104-121 a.u./sec/W)
  ✓ A modest (~16%) increase in slope with integration time is observed,
    possibly reflecting improved averaging and reduced noise rather than
    intrinsic sensitivity change

Possible Physical Interpretations:
  • Slight increase with time → improved signal averaging reduces noise floor
  • Constant sensitivity → ideal detector behavior
  • Decreased sensitivity → detector heating or saturation onset
